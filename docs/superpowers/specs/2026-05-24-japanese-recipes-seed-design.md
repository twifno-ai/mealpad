# 经典日餐食谱种子数据

**日期：** 2026-05-24  
**状态：** 已完成  
**实现计划：** [2026-05-24-japanese-recipes-seed.md](../plans/2026-05-24-japanese-recipes-seed.md)

## 目标

为 Mealpad 食谱库追加 **120 道** 家庭日料 + 外食常见菜（家庭可简化版），与现有中餐 seed **并存**，供 AI 填充每餐与手动选菜使用。

内容在实现阶段由 **Cursor Agent 编写** JSON，经 **独立一次性脚本** 写入 SQLite，**在已有食谱（含中餐 seed）基础上追加**。

## 已确认决策

| 项 | 选择 |
|---|---|
| 内容来源 | Cursor Agent 生成 JSON 数据 |
| 写入方式 | 一次性 Python 导入脚本，手动执行 |
| 触发时机 | **不**绑定 server 启动 / lifespan |
| 去重 | **按完整 `name` 去重** — 与 DB 已有或本批已导入同名则跳过，不覆盖 |
| 与现有库 | **追加**；与中餐 seed 可先后或分别导入 |
| 总量 | **120 道** |
| 类型配额 | **meat 50 / veg 30 / soup 20 / other 20** |
| 风格 | **J2** — 家庭日料 + 外食常见（寿司卷、天妇罗、拉面、大阪烧等，做法家庭化） |
| 菜名 | **L3** — 中文（日文），如「照烧鸡腿（照り焼きチキン）」 |
| 描述与食材 | **中文**；`description` **含制作步骤**（见下） |
| 数据形态 | 4 个 `japanese_recipes_*.json` + 独立 `make seed-japanese-recipes` |
| 实现架构 | **通用 SeedBundle** 重构现有导入逻辑（方案 1），中餐测试保持通过 |
| 封面图 | 无 |

## 数据文件

路径：`backend/data/seeds/`（与 `classic_recipes_*.json` 同目录）

| 文件 | type | 条数 |
|---|---|---|
| `japanese_recipes_meat.json` | `meat` | 50 |
| `japanese_recipes_veg.json` | `veg` | 30 |
| `japanese_recipes_soup.json` | `soup` | 20 |
| `japanese_recipes_other.json` | `other` | 20 |

每条记录对齐 `RecipeCreate`：

```json
{
  "name": "照烧鸡腿（照り焼きチキン）",
  "type": "meat",
  "description": "1. 鸡腿用刀背拍松，与照烧酱、米酒、姜一起腌 15 分钟。\n2. 平底锅少油，中火将鸡皮朝下煎至金黄，翻面继续煎。\n3. 倒入剩余腌汁，小火收浓至酱汁包裹，撒白芝麻即可。",
  "ingredients": ["鸡腿 2只", "照烧酱 3勺", "米酒 1勺", "姜 2片", "白芝麻 少许"]
}
```

**字段规则：**

- `name`：L3 格式，`中文名（日文名）`，使用全角括号 `（）`；120 条内互不重复；与中餐 240 条之间也尽量不重复（去重按完整字符串，含括号内日文）
- `type`：与文件名一致
- `description`：**必填**，中文 **制作步骤**，格式如下：
  - 使用 `\n` 换行；前端 `textarea` 可直接展示
  - 每步以 **`数字.` + 空格** 开头，如 `1. `、`2. `
  - 每道菜 **3–6 步**，家庭厨房可操作，不写过多专业术语
  - 不写菜名重复介绍句；步骤即描述全文
- `ingredients`：非空数组，4–8 项中文自由文本

**内容质量（J2）：**

- **meat：** 照烧、生姜烧、炸物、鱼介主菜、烧鸟风、肉じゃが等
- **veg：** おひたし、筑前煮（素）、炒野菜、冷奴、温野菜等
- **soup：** 味噌汁、豚汁、けんちん汁、吸い物、雑煮（简版）等
- **other：** 各类丼、咖喱饭、蛋包饭、乌冬/拉面/荞麦、大阪烧、饭团、家庭寿司卷等

## 导入架构

### 重构：`backend/app/services/recipe_seed.py`（新）

从 `classic_recipes_seed.py` 提取通用逻辑：

```python
@dataclass(frozen=True)
class SeedBundle:
    name: str
    seed_files: tuple[str, ...]
    file_type: dict[str, str]
    expected_counts: dict[str, int]

CLASSIC_BUNDLE = SeedBundle(...)
JAPANESE_BUNDLE = SeedBundle(...)

def import_recipe_seeds(session, bundle, seeds_path=None) -> ImportResult: ...
def validate_production_seeds(bundle, seeds_path=None) -> dict[str, int]: ...
```

`classic_recipes_seed.py` 保留为薄包装，导出 `import_classic_recipes` / `validate_production_seeds`（默认 `CLASSIC_BUNDLE`），**现有测试与 CLI 行为不变**。

### 日餐 CLI

- **脚本：** `backend/scripts/import_japanese_recipes.py`
- **Makefile：** `seed-japanese-recipes`
- **行为：** 与中餐相同 — 加载 DB 名 → 顺序 `meat→veg→soup→other` → skip 同名 → 单次 commit → 打印 imported/skipped

```makefile
seed-japanese-recipes: setup-backend
	cd backend && .venv/bin/python scripts/import_japanese_recipes.py
```
