A family-oriented meal planning and recipe management tool that can save recipes, plan what to eat by week/day, and automatically generate a shopping list based on the meal schedule—reducing repetitive decisions and preventing missed ingredients. This tool should at least have the following functions:

1. This tool should be a mobile app or mobile web app that with a server that can be used in local network
2. This tool should be able to save recipes, including description, ingredients, type (soup, meat etc).
3. This tool should be able to use AI agent to generate meal plan from the saved recipes.
4. This tool should be able to generate a shopping list based on the meal plan
5. The meal plan should be able to be updated manually
